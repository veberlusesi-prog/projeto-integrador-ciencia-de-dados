# Apresentação — Projeto Integrador de Ciência de Dados

Esta pasta contém os materiais utilizados na apresentação final do projeto **Port Alder**, uma análise de dados hoteleiros de uma cidade fictícia.

## Arquivos

- `apresentacao_port_alder.pptx`: apresentação em formato PowerPoint, permitindo edição dos slides.
- `apresentacao_port_alder.pdf`: versão em PDF, disponível para visualização e compartilhamento.

## Objetivo

Apresentar as principais etapas do desenvolvimento do projeto, incluindo exploração e preparação dos dados, análise estatística, banco de dados, visualizações e desenvolvimento de um dashboard interativo.

## Observação

Os dados utilizados no projeto são sintéticos e representam um cenário fictício.
