# Dados do Projeto

Esta pasta armazenará os arquivos do dataset Nice Rooms, utilizado nas análises de Ciência de Dados.

Os dados representam 14 hotéis fictícios da cidade de Port Alder, durante os anos de 2027 e 2028.
